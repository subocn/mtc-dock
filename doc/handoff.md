# 对接充电桩时的字段交出

作者：苏勃(subo)

许可：Apache-2.0，全文见仓库根目录 `LICENSE`。

BMS 不上桩侧线。充电机只在下列条件都成立时，把本链路字段交给桩侧。桩的报文、枪和导引不在本文。BMS 口的超时仍用 `mtc-link` 的链路剖面。家充剖面在 `mtc-solo`。桩侧超时不改 BMS 口。

充电已经结束后，在 `chg_pile_restart` 允许下一次握手之前，不交出新的能量传输需求。暂停不按结束处理。可以交出的本链路字段是 `0x01` 的请求电压和请求电流，以及 `0x04` 的 28 字节：荷电、包实测电压、最高和最低单体电压及其序号、最高和最低温度及其传感器序号、额定容量、额定电压、化学体系、允许电压、允许电流、允许温度、剩余时间，以及绝缘、连接器、单体过压、单体欠压、过温和低温。电气匹配未通过、选用的加密没有核对通过、`0x04` 有效位为 0，或超过 3 秒没有新的合法 `0x04` 时，这些字段不交出，也不进入桩侧能量传输。车架号、软件版本、厂家、序列号、生产日期和循环次数不在 `0x04` 里，保持 0。过温和低温不写入桩侧 BSM 字节 6，也不因此结束。模拟器短装不保存包实测电压和四个序号，BCS 短装不写剩余时间。产品按第 11 章组帧，序号和包实测电压从充电机保存的 `0x04` 取。

交出不等于原样抄写。交流桩不把请求电压和请求电流译成 BCL 或 CurrentDemandReq。直流桩的目标电压写调用方传入的书面输入窗口与桩输出范围的交集，不写电池口请求电压。目标电流按电池侧功率、目标电压和调用方给出的效率换算，不把 `0x01` 的安培数原样写入。换算在 `mtc-link` 的 `chg_ac_inlet_01a`、`chg_ac_batt_01a`、`chg_dc_pile_demand`、`chg_dc_batt_01a`、`chg_gb_dc_i_raw`、`chg_gb_dc_i_phys`、`chg_gb_dc_cml_i` 和 `chg_pile_restart`。本文件仍只规定能否交出，不组桩侧帧。

下面是本链路字段与桩侧报文的对应，供翻译使用。它不声明通过某项充电桩国家标准。

## 12. 桩侧映射与公开规范对照

BMS 不上桩侧线。充电机把第 5 节的字段翻译到桩侧。路径见图 21（桩侧翻译）。下列对照不改变第 3 节和第 4 节的规则。


### 12.1 桩侧标准对应映射

**术语声明。** 本节中"充电机"指本链路所述的直流充电机（含家充、车载、壁挂直流、交直流一体机），"桩"或"桩侧"指充电机面向国标 / 欧标 / 美标 / CHAdeMO 的外部设备（BMS 不直接连接桩）。"桩侧线"指充电机 ↔ 桩之间的通信线（S+/S−、CC2、CP、电子锁）；"本链路"指 BMS ↔ 充电机 之间的一线通 / CAN / RS-485。

BMS 不直接连接国标桩、欧标桩或美标桩。充电机把本链路的字段翻译过去。桩侧线仍止于充电机。交流桩不翻译成 BCL 或 CurrentDemandReq，也没有桩侧电压请求。国标交流用控制导引 PWM 和 CC，不用 GB/T 27930。欧标交流用 IEC 61851-1 和 Type 2 的 PP，不用 GB/T 27930，也不用 ISO 15118。国标直流是 GB/T 27930-2023 A 类。欧标直流是 DIN SPEC 70121，ISO 15118-2 仅在调用方写明时启用，不用 GB/T 27930。本节不声明通过 GB/T 34658。

交流进线由 `chg_ac_inlet_01a` 计算。只有控制导引标称 6 V 可以取电。低于 3%、高于 7% 且低于 8%、高于 97% 为 0，数字电流也不放开。3% 至 7% 没有模拟电流；调用方未给出数字电流时不得取电，已经给出非零数字电流时取该电流、电缆档与额定的较小者。8% 至不足 10% 为 6 A。10% 至 85% 为占空比百分数 × 0.6 A。高于 85% 至 96% 为（百分数 − 64）× 2.5 A，不得改用 ×0.6。高于 96% 至 97% 为 80 A。这两档再与电缆档和额定取较小者，单相不得超过 32 A。电阻只认 1.5 kΩ、680 Ω、220 Ω、100 Ω。国标为 10 A、16 A、32 A、32 A。欧标为 13 A、20 A、32 A、32 A。680 Ω 在欧标是 20 A，不是 16 A。100 Ω 单相不取 63 A。不在这四档时允许电流为 0。额定为 0 时结果为 0。8% 至 97% 已经有模拟电流时，数字限流只再取较小者。数字限流未提供时不另造。`chg_ac_batt_01a` 只下调电池侧电流，上限向下取整。不改已保存的 `0x01`。效率由调用方传入，传入 0 或大于 1000 时结果为 0。书面交流电压窗口两端都为 0 时不检查，也不另定上下限。只传入一端、下限高于上限或实测落在窗外时结果为 0。

直流目标由 `chg_dc_pile_demand` 写出。国标直流与欧标直流量值用同一函数。没有书面输入窗口、窗口非法、没有桩的电压范围、电压任一端为 0、电流上限为 0、下限高于上限、效率为 0 或大于 1000、电池请求电压或电流为 0、两个范围没有交集时不发送请求。电流下限为 0 表示桩没有下限。未收到电流能力时把上限传 0。进线在交集内用进线。进线在本机窗口内但高于交集上限时向下取上限，低于下限时取下限，并按取定后的电压重算电流。没有实测且上一次目标在交集内时用上一次；否则用交集下限。进线在本机窗口外不发送，不得把电池口电压钳进窗口。电流向上取整到 0.1 A，再与桩最大取较小者。小于桩最小时不发送。下限为 0 时不因此拒绝正电流。放不进 16 位时不发送。暂停不看效率。暂停时电压保持上一次仍在交集内的值，电流只向下钳。上一次电压不在交集内，或电流低于桩最小时不发送。电流不把 `0x01` 的安培数原样写入。`chg_dc_batt_01a` 用已经与桩最大取过小的电流把电池侧请求向下取整，不得超过请求。结果为 0 时电池口不出流，桩侧改发停止。国标直流 CAN 的充电电流由 `chg_gb_dc_i_raw` 编成 4000 减 0.1 A 计数。40.0 A 是 3600，不是本链路 BCL 的 4400。`chg_gb_dc_i_phys` 做相反换算，原始值大于 4000 时失败。`chg_gb_dc_cml_i` 把 CML 最大与最小充电电流按幅值还原成区间，标签写反仍得到同一区间，最小解出 0 表示没有下限。欧标 EXI 不用这个原始值。

四种桩侧系统的物理层与控制导引：

- 国标桩用 CAN。逐字段换算见第 12 节。GB/T 27930-2023 相对 2015 版删除的是「用请求 PGN 向对方索取参数组」，CHM、BHM、CRM、BRM 仍在。本链路同样不设查询报文。
- 欧标和美标直流用 CP 上的 PLC（ISO 15118-3、SAE J2931/4）。车辆先发送 ChargeParameterDiscoveryReq，给出电压、电流限值和荷电状态；能量传输循环中发送 CurrentDemandReq，给出目标电压和目标电流。充电机内的协议栈做这层组装。DIN 70121 是不含即插即充的直流子集。SAE J2847/2 使用同一类直流能量传输报文。
- CHAdeMO 属于 IEC 61851-24 系统 A，CAN 为 500 kbit/s、11 位标识符。车辆是总线主站，周期发布电池参数和电流请求。
- 上述规范里，电流请求都由车辆发出。本链路由 BMS 先发 0x01，与这一惯例一致。
- GB/T 27930-2023：BCL 电流需求低于充电机最小电流时，桩按最小电流输出；电压需求低于最小电压时，桩发 CST 停机。2015 版一些桩在电压或电流需求为 0 时也按最小电流续出。本链路不同：请求电流为 0 或请求电压为 0 时，输出为 0 A。翻译到桩侧时见第 12.2 节，能量传输中的 0 A 请求变成 BST，不发送电流为 0 的 BCL，并进入结束。暂停不是结束。
- B 类、超充和 GB/T 27930.2-2024 的 V2G 不在本链路内。

### 12.2 GB/T 27930 桩侧字段映射

充电机产品在桩 CAN 上按 GB/T 27930-2023 第 11 章组帧。桩 CAN 与 BMS 通信 CAN 不共线。不把本链路的 BSM、CCS 短装原样搬过去。

下表是 `chg_evcc` 把本链路事件译成它自己的短装。它用来在没有实桩时核对发没发、超时怎么停。表里的字节不是第 11 章的定义。

标识符按源地址读：`56` 是充电机，`F4` 是 BMS。模拟器在同一条总线上两侧都发。电池侧 CAN 上，产品充电机只发源地址 `56`，接收源地址 `F4`。面向实桩时本机充当车辆，发送源地址 `F4`，接收源地址 `56`。不得把「只发 56」用到桩 CAN 上。

| 本链路现象 | 桩侧动作 |
|--------------|----------|
| 本链路进入停止（停止位、BST，或能量传输中一线通、RS-485 的请求电流变为 0） | 桩侧发 BST 并进入结束，输出为 0，500 ms 内停止发送 BCL，CRO = 00。桩侧不发电流为 0 的 BCL。正常结束不置枪锁。直接回到能量传输不恢复 BCL；回到握手或参数配置后可以重新握手。本链路自己若只收到 BCL 电流 0、没有 BST，仍输出 0 A 且会话保持 |
| 本链路暂停，未满 10 min | 桩侧 BSM 暂停位置上。电压保持上一次仍落在交集内的值，电流只向下钳。上一次电压不在交集内或电流低于桩最小时不发需求 |
| 本链路暂停累计满 10 min | 故障码写 `0x03`，进入结束，当拍发 CST。暂停撤销不清这只锁存，阶段留在结束 |
| 参数配置阶段就绪位为 0 | CRO = 00。这一阶段不发送 BRO。CRO 保持 00 单独累计，没有 1 s 计时。满 60 s 仍为 00：CEM 字节 0 的 bit4 置 1，并结束。CRO 变为 AA 后停止累计，已累计的毫秒保留；离开参数配置阶段才清零。允许位不参与这只计时 |
| 到 1.2 s 没有 CCS，或没有 RS-485 的 0x03，或没有合法 0x01 | 按第 3 节停止。不满 1 s 不停。CRO = 00 |
| 0x04 有效位为 0，或超过 3 秒没有更新 | BRM 仍发，49 字节为 0。BCP 仍发，允许值写 0，字节 7 写 0xFF。不进入桩侧能量传输。BSD 未知项写 0xFF |
| 0x04 字节 1 的低 4 位（绝缘、连接器、单体过压、单体欠压）任一为 1 | 写入 BSM 字节 6 的低 4 位，发 CST 结束，并置枪锁。须先断开再连接才清除枪锁。过温和低温在 bit4、bit5，不写入 BSM 字节 6，也不因此发 CST，也不置枪锁 |
| 充电机故障或故障码非 0 | 链路仍有效时当拍进入结束，发 CST，输出为 0，不发 BCL。不置枪锁。故障撤销后直接回到能量传输不恢复 BCL；回到握手或参数配置后可以重新握手。无故障的能量传输帧里 CCS 字节 6 为 0x01 |

字段按 GB/T 27930-2023 A 类的偏移和分辨率重新打包，多字节为小端（Intel / SAE J1939），不把 0x04 的字节原样搬过去。电压分辨率仍是 0.1 V。国标直流桩的充电电流不使用本链路第 8 节的加 4000：产品用 `chg_gb_dc_i_raw`，40.0 A 为 3600，不是 BCL 的 4400。欧标 EXI 不用这个原始值。本链路进入停止时，桩侧 BST 在进入停止当周期发送，停留期间每 10 ms 重发。故障码 0 和剩余时间 0xFFFF 在 BSD 里写成 0xFF。

**字段字节偏移详解（关键报文）**：

**BRM（49 字节）**：A 类长报文使用 SAE J1939 连接模式，不使用单帧 `0x180256F4`，也不是 B 类 LM（帧序号 0、LM_ACK，LMS_T2 = 100 ms）。DT 间隔 10 ms。

**BSM。** GB/T 27930-2023 第 11.3.4 条周期 250 ms。收到第一帧之前不以 BSM 超时中止；收到之后超过 5 s 没有下一帧，发错误报文结束，且不重新插枪不再握手。模拟器在见到断开再连接后清除枪锁。只报仍连接不清除。清除后仍须从握手或参数配置重新开始。字段含最高单体编号、最高和最低温度及其检测点编号，以及状态位。产品按这一条组帧。

模拟器 BSM 是 7 字节短装：字节 0–1 最高单体电压（0.01 V），字节 2–3 最低单体电压。毫伏换算四舍五入，3900 mV → 390，3905 mV → 391。字节 4 和字节 5 为最高、最低温度加 40。低于 −40 °C 写 0，高于 210 °C 写 250。字节 6 为私有标志。暂停为 `0x00`，未暂停为 `0x10`。低 4 位是一位一个故障，不是国标里两位一组的状态。过温和低温不在这一字节。荷电不在这 7 字节里，80% 不会写成 80。这不是第 11.3.4 条的字节顺序。BCS 的最高单体电压用同一套四舍五入。`0x04` 字节 4–5 的包实测电压和字节 24–27 的四个序号已经在 BMS 帧里，充电机按字节保存。模拟器内部电池结构不保存这五项，短装发不出来。产品组第 11.3.4 条时从保存的 `0x04` 取序号。

**CCS。** GB/T 27930-2023 第 11.3.3 条含输出电压、输出电流（偏移 −400 A）、累计充电时间，以及 SPN3929：`00` 表示暂停输出，`01` 表示继续。车辆超过 1 s 未收到 CCS 应发错误报文。下表是模拟器的 8 字节短装：字节 4 和字节 7 写 0，字节 5 表示正在输出，字节 6 的 `01` 表示无故障。累计时间和能量只写在 BSD。

**模拟器 CCS（8 字节短装）**：

| 字节偏移 | 含义 | 分辨率 | 来源 |
|----------|------|--------|------|
| 0–1 | 输出电压 | 0.1 V/bit，小端 | `meas.v_out_01v`。83.6 V → `44 03` |
| 2–3 | 输出电流 | 0.1 A/bit，偏移 −400 A，小端 | `meas.i_out_01a`。39.8 A → `2E 11` |
| 4 | 累计时间 | min | 实时帧保持 0。会话累计在 BSD |
| 5 | 充电机状态 | bit | 仅 `outputting`：1 = 功率级已闭合（dc_path / ac_path 已在本链路 §5.5 表达，不在 CCS 中重复） |
| 6 | 故障标志 | enum | 仅 `0x01` 无故障，`0x00` 立即停止。这不是国标 SPN3929 的暂停。其他值丢掉，不刷新 T_loss |
| 7 | 累计能量 | 0.1 kWh | 实时帧保持 0。会话累计在 BSD |

**CST (4 字节)**：充电机中止充电报文（GB/T 27930-2023 §6.5.4 表 14）。

|----------|------|--------|------|

**CEM (4 字节，PGN7936)**：超时位图，不是累计能量。累计充电时长和能量只写在 BSD。

**BRM**：49 字节，A 类使用 J1939 连接模式，不是 B 类 LM。模拟器先发 TP.CM RTS（`0x1CEC56F4`，控制字节 0x10，总长 49，7 包）。收到 CTS（`0x1CECF456`，控制字节 0x11）后发 DT（`0x1CEB56F4`），间隔 10 ms。没收到 CTS 不发 DT。字节 0–2 协议版本，字节 3 电池类型，字节 4–5 额定容量，字节 6–7 额定电压，字节 22 产权标识写 1。VIN 与软件版本保持 0。本仓库不声明通过 GB/T 34658。

**暂停恢复的冲击电流。** GB/T 18487.1-2023 第 10.7.2 条：直流接触器再次接通时，冲击电流峰值不超过 20 A。第 C.7.6.2 条：恢复前把输出电压调到接口当前电压减去 1 V～10 V，再闭合接触器。本链路暂停撤销的第一拍，输出电流钳在 20.0 A。电压目标为已经按锁压钳位后的目标再减 1.0 V；请求不高于锁压时，这就是请求电压减 1.0 V。高出锁压不超过 0.5 V 的请求先停在锁压，再减 1.0 V。下一拍恢复跟随请求。这一拍只改电池口输出。桩侧暂停仍保持上一次仍在交集内的电压需求，不把减过 1.0 V 的电池口目标写入桩侧。

**超时分档。** 本链路的 BCL 与 CCS 用 T_loss：标称 1 s，不满 1 s 不停，到 1.2 s 输出为 0。模拟器在参数配置阶段对 CRO 保持 00 计 60 s，这一阶段不发送 BRO；没有另外的 5 s 缺失计时。国标 BSM 是收到第一帧后再过 5 s；模拟器不在总线上数 BSM 帧，而是电池数据一度有效、之后失效再满 5 s，才置 CEM 字节 1 的 bit4 并锁住。模拟器没有 BCS 的 5 s 超时。本链路里，标称不小于 50 ms 的报文，间隔在 ±10% 以内不结束会话。模拟器接收侧只观察 BCL 和 BSM：50 ms 允许到 55 ms，56 ms 置迟到；250 ms 允许到 275 ms，276 ms 置迟到。迟到不结束会话。优先级、源地址或目的地址不符，或 BCL 不足 5 字节、BSM 不足 7 字节，丢掉且不把已有的间隔计时清零。本链路充电机判定暂停只看 BSM 字节 6 的 bit4，`0x20` 仍暂停，`0x30` 不暂停。

累计时间和累计能量只写在 BSD。CEM 只发超时位，不带时间和能量。`charge_time_ms` 在进入能量传输时清零，按 `dt_ms` 累加。能量在 `outputting` 为 1 时按 `v_01v × i_01a × dt_ms / 3.6e8` 积分。

**桩侧四阶段时序（按国标改写）**：

```
阶段 1 握手 250 ms-3 s
  CHM↔BHM（充电机↔桩）
  CRM↔BRM
阶段 2 参数配置 250 ms-1 s
  BCP↔CML
  BRO↔CRO（充电机就绪位 = 1）
阶段 3 充电（能量传输）
  BCL 与 CCS 为 50 ms。BRO、BSM、BCS、CRO 为 250 ms
  暂停留在本阶段，不发 BST
  请求电流为 0 且不是暂停：进入阶段 4，输出为 0，发 BST，不发电流为 0 的 BCL
阶段 4 结束
  进入当拍发 BST，之后每 10 ms 重发
  输出为 0，不得维持充电电压
  有故障时进入当拍发 CST
  BSD 每 250 ms
  CEM 仅在超时位非 0 时发送。正常停止不发 CEM
```

充电机不把 BCL、BRO、BSM、BST 原样转到桩 CAN。直流桩的电压和电流用 `chg_dc_pile_demand` 计算，不把 `0x01` 的请求电压和请求电流原样写入。国标直流电流再用 `chg_gb_dc_i_raw`。模拟器短装不得发给实桩。BMS 不处理桩侧报文。

国标桩的 S+/S−、CC2、电子锁、CP 由充电机侧的桩 CAN 与桩侧协议栈处理，止于充电机内部，不在本链路之内。本链路与桩侧信号完全电气隔离。

### 12.3 与公开规范的对照

下列对照不改变第 3 节的数值。

- GB/T 27930-2023 第 9 章把 A 类充电分成物理连接、低压辅助上电、握手、参数配置、充电、结束。附录的正常充电时序把报文与辅助电源、电子锁、直流接触器画在同一张图上。本文第 3 节按这个画法，把控制报文和强电放在同一行；私有链路的阶段名仍以第 3 节为准。
- SAE J1939-21 的 PDU1 把 29 位标识符分成优先级、保留位、数据页、PF、PS 和源地址。CAN 实现结构按该位域装帧，不另造标识符。GB/T 27930-2023 的 PDU 用扩展数据页描述同一位，本文标识符图仍标为 R，与现有组帧一致。
- GB/T 27930-2023 把 BCL、CCS 超时写成 1 s。本链路标称 1 s，不满 1 s 不停，到 1.2 s 输出为 0。BCL 周期 50 ms，BRO、BSM 250 ms。2023 版删除的是请求 PGN，车辆仍按周期发送 BCL，充电机不索取。
- 国标在收到第一帧 BSM 之后，5 s 没有下一帧判为超时；第一帧到达前，不因 BSM 超时停止充电。本链路的电池信息超过 3 s 视为失效，家充仍按 `0x01` 出流，不刷新 T_loss。模拟器在失效之后再计 5 s，才发 CEM 并把枪锁置 1。枪锁置 1 之后，必须先见到断开再连接才清除。只报仍连接不清除。清除后直接回到能量传输仍不发 BCL，回到握手或参数配置才允许新会话。这两只计时器前后相接，不是同一只。
- GB/T 27930-2023 第 11.3.1 条：BCL 电流需求低于充电机最小电流时按最小能力输出；电压需求低于最小电压时发 CST 停止。本链路不按最小能力续出：需求低于桩最小电流时不发送该帧。能量传输中请求电流为 0 且不是暂停时发 BST，不发电流为 0 的 BCL。第 5.4 条：公共场站充电电流数据值为负，范围 −400 A～0 A。本链路自己的 BCL 与 CCS 仍是 0.1 A 计数加 4000，40.0 A 为 4400。模拟器短装使用这一编码，不得发给实桩。产品发往国标直流桩的充电电流由 `chg_gb_dc_i_raw` 编成 4000 减 0.1 A 计数，40.0 A 为 3600。握手电流 0 留在握手。能量传输中一线通和 RS-485 的请求电流 0 结束会话。CAN 上只收到 BCL 电流 0、没有 BST 时输出 0 A，会话保持。桩侧在能量传输中请求电流为 0、且不是暂停时，进入结束，输出为 0，发 BST。下一拍仍停在能量传输时，即使电流恢复也不再发 BCL。
- 国标握手相关超时合计为 5 s，报文仍包括 CHM、BHM、CRM、BRM、BCP、CML。本链路用 3 帧 0x01 或一次 CRO = AA 完成私有握手，电池参数放在 0x04，对应国标里先有 BCP、后有 BCL 的顺序。
- ISO 15118-2 与 DIN 70121 由车辆发送 ChargeParameterDiscoveryReq，再在能量传输循环中发送 CurrentDemandReq。CHAdeMO 由车辆担任 CAN 主站。本链路由 BMS 先发 0x01，0x04 在非零电流之前至少送出一次。
- CRC-16 与 Modbus RTU 相同：多项式 0xA001，初值 0xFFFF，低字节在前。CAN 的 CRC-15 由控制器完成。GB/T 27930 与本链路的多字节字段均为小端（Intel）。
- `0x18EF56F4` 的 PF 为 0xEF（239），属于 J1939 PDU1。SAE J1939-21 把 PGN 61184 命名为 Proprietary A，PDU Specific 是目标地址。本规范把目标填 0x56、源地址填 0xF4，与 GB/T 27930 的 PGN 不冲突。
- 本链路不实现 GB/T 27930.2-2024 的 V2G、超充，以及 GB/T 18487.1 附录 C 的 B 类。充电机不按寄存器查询电池。
